# MotionBricks for Blender (unofficial)

Free Blender add-on that imports motion generated by **NVIDIA MotionBricks** as an animated SOMA
character, with the scene's greybox cubes, a checker floor, a sun and a follow camera.

- **Add-on** (`addon/motionbricks_importer`): `File › Import › MotionBricks (.npz)` and a
  **MotionBricks** tab in the 3D Viewport sidebar (`N`). Blender 4.2 or newer (tested on 5.1.2 and 5.2.3 LTS).
- **Recorder** (`recorder/mb_record.py`): runs MotionBricks' Scene Preview and saves what you play
  to an `.npz` file for the add-on.

> [NVlabs/motionbricks](https://github.com/NVlabs/motionbricks) (SIGGRAPH 2026).

## What you need

- An NVIDIA RTX GPU with a recent driver (MotionBricks uses TensorRT). Windows or Linux.
- [Git](https://git-scm.com/), [Git LFS](https://git-lfs.com/), [uv](https://docs.astral.sh/uv/)
- [Blender](https://www.blender.org/download/) 4.2 or newer
- About 12 GB of disk space for MotionBricks (models, Python environment, TensorRT cache)

## 1. Install MotionBricks

```sh
git clone --branch v0.2.0 https://github.com/NVlabs/motionbricks.git
cd motionbricks
git lfs pull
uv sync
```

The first launch builds a TensorRT plan for your GPU, which takes a few minutes. Try the official demo:

```sh
uv run python -m app.scene_preview --scene assets/scenes/soma_gym.scene.json
```

## 2. Record a motion

Download this repository (green **Code › Download ZIP**, or the release below). From the
`motionbricks` folder, run the recorder:

```sh
uv run python path/to/motionbricks-blender/recorder/mb_record.py --scene assets/scenes/soma_gym.scene.json --out my_walk.npz
```

The Scene Preview window opens. Walk with **W A S D**, run with **Space**, walk into the boxes to
jump, vault, duck or sit. **Close the window to save.** The motion is saved at 30 fps.

A windowless recording follows a key timeline instead, and gives the same motion every time:

```sh
uv run python path/to/mb_record.py --scene assets/scenes/soma_gym.scene.json --out run.npz --script "0:,1:w,6:w+space,9:w" --seconds 14
```

You can build your own greybox course with `uv run python -m app.scene_editor` and record it with `--scene`.

## 3. Install the add-on

1. Download `motionbricks_importer-0.1.0.zip` from the
   [Releases](https://github.com/hyun2xyz/motionbricks-blender/releases) page. Do not unzip it.
2. In Blender: **Edit › Preferences › Add-ons**, open the **⌄** menu at the top right, choose
   **Install from Disk…** and pick the zip.
3. Make sure **MotionBricks Importer (unofficial)** is ticked.

## 4. Import

- **File › Import › MotionBricks (.npz)**, or press **N** in the 3D Viewport, open the
  **MotionBricks** tab and click **Import Motion (.npz)**.
- Options in the file browser: start frame, frame range and FPS, greybox cubes, checker floor, sun, follow camera.
- Press **Space** to play. Render with EEVEE or Cycles as usual.

The add-on builds an armature whose rest pose is the SOMA bind pose, so Blender's armature deform
matches MotionBricks' own skinning. Every frame is keyed, so you can edit, retime or bake it like any action.
